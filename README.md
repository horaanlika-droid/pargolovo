# Futurama Shop — обменник подарочных карт

Сайт-обменник в стиле мультфильма **Футурама** (New New York, 3000 год). Весь интерфейс на русском.

## Что внутри

- **Название:** Futurama Shop
- **Маскоты:** Бендер, Фрай, Лила и Доктор Цойдберг (нарисованы на чистом CSS)
- **Подарочные карты — главный блок:** у каждой карты свой курс!
  - 9 карт: Apple & iTunes, Google Play, Steam, PlayStation, Xbox, Amazon, Netflix, Spotify, Ozon
  - Для каждой — отдельный курс покупки и продажи (например, Apple 82,50 ₽ / 94,80 ₽ за 1 $, Steam 77,80 ₽ / 90,50 ₽)
  - Своя комиссия, свой тренд, своё изменение за день — курсы живут независимо и обновляются каждые 3 секунды
  - Калькулятор: выбери карту → введи номинал → сразу видишь выплату в рублях
  - Фильтры по категориям: Все, Игры, Магазины, Подписки, Россия
  - Таблица «Курсовая доска подарочных карт» — покупка/продажа/динамика для каждой карты
- **Обменник валют:** конвертация USD, EUR, RUB, GBP, JPY, BTC с живым курсом (доп. блок)
- **Отзывы клиентов** от маскотов
- **Фон:** анимированный Нью-Нью-Йорк с летающими кораблями

## Почему «свой курс для каждой»

Раньше был один общий спред. Теперь:

```js
buyRate: 82.50  // мы покупаем у клиента
sellRate: 94.80 // мы продаём клиенту
fee: 2.5%       // уже включена в курс карты
```

Каждая карта в массиве `GIFT_CARDS` хранит свои `buyRate`/`sellRate`/`fee`/`change`. При `tickRates()` каждая карта дёргается своей случайной дельтой `±0.4%` — курс Steam может расти, а Google падать одновременно.

## Стек

Чистый HTML / CSS / JS, без сборщиков и зависимостей. Открой `index.html` в браузере.

## Запуск

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Язык

Весь сайт на русском: заголовки, описания, кнопки, подсказки, алерты, таблица курсов, калькулятор.
