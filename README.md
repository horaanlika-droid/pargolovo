# Futurama Shop

Сайт-обменник валют в стиле мультфильма **Футурама** (New New York, 3000 год).

## Что внутри

- **Название:** Futurama Shop
- **Маскоты:** Бендер, Фрай, Лила и Доктор Цойдберг (нарисованы на чистом CSS, каждый со своей репликой)
- **Обменник валют:** конвертация между USD, EUR, RUB, GBP, JPY и BTC с актуальным курсом
- **Курсовая доска:** покупка/продажа с роботской комиссией (2,5 % спред) и изменением курса
- **Отзывы клиентов:** от наших маскотов
- **Фон:** анимированный Нью-Нью-Йорк с летающими кораблями

## Стек

Чистый HTML / CSS / JS, без сборщиков и зависимостей. Открывайте `index.html` в любом браузере.

## Запуск

Локально:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000

## Стили

Палитра Футурамы: неоновый циан, маджента, пурпур, жёлтый, жирные чёрные контуры, мультяшные шрифты (Bangers, Permanent Marker, Comic Neue).
